## FluxVisuals v1.0.28 — первый план для косметики

- Перед загрузкой аватара в Figura теперь вставляется скрипт, скрывающий модель от владельца в первом лице (`renderer:isFirstPerson()` + `models:setVisible`). Раньше скрипт не добавлялся в `avatar.json`, поэтому Figura его не выполняла и камера оказывалась внутри модели.
- В остальном сохранены исправления v1.0.27: хотбар и все HUD-элементы снова рисуются, инвентарь не перекрывается.

## FluxVisuals v1.0.27 — исправление рекурсии в HUD

- Устранён `StackOverflowError` в `Hud.drawClientRect`: после хотфикса v1.0.26 оставалась ветка, которая вызывала тот же метод снова. Из-за этого панели HUD оставались пустыми.
- Окончательно отключено размытие HUD во всех путях отрисовки.

## FluxVisuals v1.0.26 — срочный хотфикс отрисовки

- Убрано размытие/liquid-glass из HUD: вложенный RenderPass ломал текст, иконки и предметы в GUI. Стекло осталось только в ClickGUI.
- HUD-оверлей больше не рисуется поверх инвентаря, креатива и других экранов — только в мире и в чате.
- Исправлен `NullPointerException` в `Keybind List` для модулей без иконки (падение EventManager каждый кадр).
- Лицензия Twemoji перенесена из `textures/gui` в отдельную папку — больше нет ошибки «Invalid path in mod resource-pack».

## FluxVisuals v1.0.25 — новый HUD и расширенная косметика

- HUD переработан по единому дизайну: ватермарк, кастомный хотбар, броня, инвентарь, медиаплеер, хоткеи, зелья и кулдауны.
- Панели HUD используют существующий liquid-glass pipeline; снимок кадра делается до ванильного HUD.
- Исправлено восстановление FBO в мосте рендера (`GL_DRAW_FRAMEBUFFER_BINDING`/`GL_READ_FRAMEBUFFER_BINDING`).
- Hud всегда включается при инициализации клиента, поэтому оверлей не пропадает после сброса конфига.
- Кастомный хотбар заменяет ванильный, сохраняя стандартные полоски здоровья, голода и опыта.
- В Cosmetics добавлено 61 новое нейтрально названное оружие с иконками; всего 73 папки `weapon-*`.
- Иконки подобраны из лицензионно чистых наборов, атрибуция — в `fluxvisuals/WEAPON_ICON_CREDITS.md`.
- Названия косметики берутся из `avatar.json`, а не из имени папки.
- Медиаплеер читает системную медиа-сессию Windows без внешних нативных библиотек.
- Добавлен компактный список хоткеев (элемент `Hotkeys`, по умолчанию выключен, чтобы не дублировать `Keybind List`).
- Удалены упоминания сторонних клиентов и проектов в исходниках, локализации и текстах интерфейса.

## FluxVisuals v1.0.16 — Полный рерайт HUD из внутреннего прототипа

### 🎯 Полный рерайт TargetHUD (из внутреннего прототипа TargetHudElement)
- **Полностью переписан** под архитектуру внутренний прототип
- **Увеличен текст**: никнейм 9.0F (было 6.5F), HP 8.0F (было 5.5F)
- **Видимость**: в чате показывает последнюю зафиксированную цель, в игре — цель под прицелом/наведением
- **HP читает реальное здоровье** (`prevTarget.getHealth()`), не анимированное — не "зависает" на одном значении
- Анимация здоровья/поглощения, скролл имени, предметы цели
- Glass/Blur стиль, частицы при уроне

### 🎯 Полный рерайт HotBarHUD (из внутреннего прототипа HotbarElement)
- **Полностью переписан** под архитектуру внутренний прототип
- **НЕ перетаскиваемый** — позиция строго ванильная (offset 22)
- **Предметы выровнены** — использует `halfWidth - HOTBAR_WIDTH/2` для всего хотбара
- Индикатор выбранного слота с анимацией (как в оригинале)
- Оффхенд слот слева/справа в зависимости от главной руки
- Glass/Blur стиль хотбара
- Рендер через InGameHudMixin (как в оригинале), отменяет ванильный рендер

### ✅ ClickGUI — починен рендер
- Добавлен вызов `GuiClient.registerEventHandlers()` в FluxVisualsClient
- GuiClient теперь регистрирует свои обработчики рендера при создании

### 🔧 Fn+F1/F2 — медиа-клавиши больше не вызывают баги
- Добавлена проверка `keyCode == 290 || keyCode == 291` (F1=290, F2=291) в:
  - KeyboardMixin — игнорирует до EventManager
  - BindingManager — игнорирует при обработке биндов
- Также добавлена проверка `client.currentScreen != null` в BindingManager — бинды не работают когда открыт экран

### 🛡 Другие исправления
- Главное меню: кнопки рендерятся при возврате с сервера/мира
- Прицел: ванильный по умолчанию (кастомный отключен)
- Убраны все дефолтные бинды (все `bind = -1`)
- Pearl Clutch Helper работает через EventScreen
- Attack Distance Indicator: числовой под прицелом, цветной, не двигается
- Mace Helper: зелёное свечение на слоте булавы в хотбаре
- Inventory HUD: стрелки на слоте, позиции 4 угла
- Vanilla fallback: если кастомный хотбар выключен — ванильный работает
