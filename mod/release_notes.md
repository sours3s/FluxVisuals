## FluxVisuals v1.0.16 — Полный рерайт HUD из GodWeer

### 🎯 Полный рерайт TargetHUD (из GodWeer TargetHudElement)
- **Полностью переписан** под архитектуру GodWeer
- **Увеличен текст**: никнейм 9.0F (было 6.5F), HP 8.0F (было 5.5F)
- **Видимость**: в чате показывает последнюю зафиксированную цель, в игре — цель под прицелом/наведением
- **HP читает реальное здоровье** (`prevTarget.getHealth()`), не анимированное — не "зависает" на одном значении
- Анимация здоровья/поглощения, скролл имени, предметы цели
- Glass/Blur стиль, частицы при уроне

### 🎯 Полный рерайт HotBarHUD (из GodWeer HotbarElement)
- **Полностью переписан** под архитектуру GodWeer
- **НЕ перетаскиваемый** — позиция строго ванильная (offset 22)
- **Предметы выровнены** — использует `halfWidth - HOTBAR_WIDTH/2` для всего хотбара
- Индикатор выбранного слота с анимацией (как в доноре)
- Оффхенд слот слева/справа в зависимости от главной руки
- Glass/Blur стиль хотбара
- Рендер через InGameHudMixin (как в доноре), отменяет ванильный рендер

### ✅ ClickGUI — починен рендер
- Добавлен вызов `GuiClient.registerEventHandlers()` в FluxVisualsClient
- GuiClient теперь регистрирует свои обработчики рендера при создании

### 🔧 Fn+F1/F2 — медиа-клавиши больше не вызывают баги
- Добавлена проверка `keyCode == 290 || keyCode == 291` (F1=290, F2=291) в:
  - KeyboardMixin — игнорирует до EventManager
  - BindingManager — игнорирует при обработке биндов
- Также добавлена проверка `client.currentScreen != null` в BindingManager — бинды не работают когда открыт экран

### 🛡 Другие исправления
- Главное меню: кнопки рендерятся при возврате с сервера/мира
- Прицел: ванильный по умолчанию (кастомный отключен)
- Убраны все дефолтные бинды (все `bind = -1`)
- Pearl Clutch Helper работает через EventScreen
- Attack Distance Indicator: числовой под прицелом, цветной, не двигается
- Mace Helper: зелёное свечение на слоте булавы в хотбаре
- Inventory HUD: стрелки на слоте, позиции 4 угла
- Vanilla fallback: если кастомный хотбар выключен — ванильный работает
